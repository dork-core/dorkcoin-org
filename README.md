# Dorkcoin Core Website

React and Vite site for Dorkcoin Core. The download center reads published releases and downloadable assets directly from the GitHub Releases API.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
```

Deploy the project on Vercel using the Vite framework preset. The default build command is `npm run build` and the output directory is `dist`.
